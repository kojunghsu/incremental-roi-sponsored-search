# Estimating Incremental Advertising ROI: A Difference-in-Differences Analysis

Estimate the incremental effect of sponsored search advertising using a **Difference-in-Differences (DiD)** framework, state the assumptions required for a causal interpretation, and evaluate ROI using **incremental traffic** rather than raw paid clicks.

---

## Project Overview

Traditional advertising ROI calculations often assume that every paid click is generated by advertising. However, for **branded keyword searches**, many users would likely visit the website through organic search even if sponsored ads were not displayed.

This project analyzes a natural experiment created by the temporary suspension of Google sponsored ads at Bazaar.com. A Difference-in-Differences (DiD) framework compares Google with unaffected search platforms to estimate incremental traffic, test identification assumptions, and translate the evidence into a scenario-based ROI decision.

---

## Business Question

**Do sponsored search ads generate truly incremental traffic, or are companies paying for clicks they would have received organically?**

This question is important because branded search users already have high intent. If many paid clicks would have occurred through organic search anyway, traditional advertising ROI can misrepresent the true business value of sponsored ads.

---

## Natural Experiment

A technical glitch suspended **Google sponsored ads during Weeks 10–12**, while ads on **Bing, Yahoo, and Ask** continued running normally.

| Component | Description |
|-----------|-------------|
| Treatment Group | Google |
| Control Group | Bing, Yahoo, Ask |
| Pre-Treatment Period | Weeks 1–9 |
| Post-Treatment Period | Weeks 10–12 |
| Outcome Variable | Total Traffic |

---

## Methodology

The analysis follows a structured causal inference workflow:

1. Identify why click-based ROI is biased
2. Define treatment, control, and identification assumptions
3. Visualize overall traffic and pre-treatment trends
4. Compare a naive pre-post model with Difference-in-Differences
5. Quantify uncertainty with a confidence interval
6. Test pre-treatment slopes and run placebo, leave-one-control-out, and trend-adjusted sensitivity checks
7. Decompose sponsored and organic traffic effects
8. Translate incremental traffic into scenario-based ROI decisions

---

## Identification and Evidence Boundary

A temporary Google ad suspension created a natural experiment for Bazaar.com's branded-search traffic. Google is the treated platform; Bing, Yahoo, and Ask form the comparison group. A causal interpretation still requires:

- Comparable untreated traffic trends across Google and the control platforms.
- No spillover of Google users to Bing, Yahoo, or Ask.
- No concurrent Google-specific event during Weeks 10-12.
- A control-platform average that is a credible counterfactual for Google.

The formal pre-treatment slope test finds a **+786 visits/week** Google-control difference (95% CI: **129 to 1,443**, p = **0.020**). Strict parallel trends is therefore not supported. The baseline DiD result is presented as a design-dependent incrementality estimate, with a pre-period placebo, leave-one-control-out analysis, and a group-specific linear-trend model used to show how conclusions change across reasonable specifications.

The panel contains only four platforms, nine pre-treatment weeks, and three post-treatment weeks. These checks improve transparency, but they do not fully resolve the identification limitation.

## Key Findings

### Verified incrementality diagnostics

| Diagnostic | Result | Interpretation |
|------------|-------:|----------------|
| Baseline DiD | **-9,911 visits/week** | Design-dependent point estimate |
| Conventional 95% CI | **-17,025 to -2,796** | Excludes zero under the specified OLS model |
| Leave-one-control-out | **-8,060 to -12,386** | Direction is consistent; magnitude varies |
| Group-specific linear trend | **-14,252 visits/week** | Direction survives a simple trend adjustment |
| Pre-treatment slope difference | **+786/week (p = 0.020)** | Evidence against strict parallel trends |
| Pre-period placebo | **+3,724 (p = 0.133)** | Not distinguishable from zero, but imprecise |

Google traffic is consistently lower after the suspension relative to the controls. However, because pre-treatment slopes differ statistically, **9,911 should not be read as a definitive causal effect**. Across the baseline, control-composition, and trend-adjusted specifications, the estimated reduction is approximately **8.1K-14.3K visits per week**.

The traffic decomposition indicates an estimated **19% organic recovery rate**: some users shifted to organic search, but the recovery did not fully replace sponsored traffic.

### Scenario-based financial translation

| Metric | Scenario Value |
|--------|---------------:|
| Incremental Conversions | **1,189** |
| Contribution Margin | **$24,975** |
| Advertising Cost | **$3,674** |
| Incremental ROI | **580%** |

The financial values use the scaled case data and assumed conversion and contribution-margin inputs. They demonstrate how an incrementality range can inform a budget decision; they are **not observed company financial results**. In practice, decision-makers should stress-test ROI across the verified traffic-effect range rather than rely on a single point estimate.

## Business Recommendation

Bazaar.com should continue investing in sponsored search advertising, but should evaluate campaign performance using **incremental impact** rather than raw click volume.

The analysis suggests that sponsored search ads generate positive incremental traffic, but the exact ROI magnitude should be interpreted with caution because the dataset is scaled. Future campaign evaluation should continue to prioritize incremental impact measurement through randomized experiments, geo-based holdout tests, or similar causal inference methods where feasible.
